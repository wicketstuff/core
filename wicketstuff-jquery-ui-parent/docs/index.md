Wicket components for jQuery UI widgets, plus Kendo UI widgets, themes and a full calendar. The Kendo grid and scheduler need a commercially licensed Kendo UI build.

## Maven

```xml
<dependency>
    <groupId>org.wicketstuff</groupId>
    <artifactId>wicketstuff-jquery-ui</artifactId>
</dependency>
```

Import `org.wicketstuff:wicketstuff-bom` in your `dependencyManagement` section to manage the version.

The [`wicketstuff-jquery-ui-samples`](https://github.com/wicketstuff/core/tree/wicket-11.x/wicketstuff-jquery-ui-parent/wicketstuff-jquery-ui-samples) module contains a runnable example application.

The [module README](https://github.com/wicketstuff/core/blob/wicket-11.x/wicketstuff-jquery-ui-parent/README.md) has more details.
