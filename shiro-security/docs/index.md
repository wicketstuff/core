Authentication and authorization for Wicket with Apache Shiro.

## Maven

```xml
<dependency>
    <groupId>org.wicketstuff</groupId>
    <artifactId>wicketstuff-shiro</artifactId>
</dependency>
```

Import `org.wicketstuff:wicketstuff-bom` in your `dependencyManagement` section to manage the version.

The [`wicket-shiro-examples`](https://github.com/wicketstuff/core/tree/wicket-11.x/shiro-security/wicket-shiro-examples) module contains a runnable example application.

Source: [`shiro-security`](https://github.com/wicketstuff/core/tree/wicket-11.x/shiro-security)
