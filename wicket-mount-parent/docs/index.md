An annotation processor that generates your page mounts at compile time.

## Maven

```xml
<dependency>
    <groupId>org.wicketstuff</groupId>
    <artifactId>wicket-mount</artifactId>
</dependency>
```

Import `org.wicketstuff:wicketstuff-bom` in your `dependencyManagement` section to manage the version.

The [`wicket-mount-example`](https://github.com/wicketstuff/core/tree/wicket-11.x/wicket-mount-parent/wicket-mount-example) module contains a runnable example application.

Source: [`wicket-mount-parent`](https://github.com/wicketstuff/core/tree/wicket-11.x/wicket-mount-parent)
