Bind key presses and other input events to components, for keyboard shortcuts.

## Maven

```xml
<dependency>
    <groupId>org.wicketstuff</groupId>
    <artifactId>wicketstuff-input-events</artifactId>
</dependency>
```

Import `org.wicketstuff:wicketstuff-bom` in your `dependencyManagement` section to manage the version.

The [`input-events-examples`](https://github.com/wicketstuff/core/tree/wicket-11.x/input-events-parent/input-events-examples) module contains a runnable example application.

Source: [`input-events-parent`](https://github.com/wicketstuff/core/tree/wicket-11.x/input-events-parent)
