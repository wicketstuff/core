Cache pages and resources with a service worker so your application keeps working offline.

## Maven

```xml
<dependency>
    <groupId>org.wicketstuff</groupId>
    <artifactId>wicketstuff-offline-mode</artifactId>
</dependency>
```

Import `org.wicketstuff:wicketstuff-bom` in your `dependencyManagement` section to manage the version.

The [`offline-mode-examples`](https://github.com/wicketstuff/core/tree/wicket-11.x/offline-mode-parent/offline-mode-examples) module contains a runnable example application.

Source: [`offline-mode-parent`](https://github.com/wicketstuff/core/tree/wicket-11.x/offline-mode-parent)
