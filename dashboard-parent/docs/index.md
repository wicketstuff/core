A simple web dashboard built from pluggable widgets.

## Maven

```xml
<dependency>
    <groupId>org.wicketstuff</groupId>
    <artifactId>wicketstuff-dashboard-core</artifactId>
</dependency>
```

Import `org.wicketstuff:wicketstuff-bom` in your `dependencyManagement` section to manage the version.

The [`dashboard-examples`](https://github.com/wicketstuff/core/tree/wicket-11.x/dashboard-parent/dashboard-examples) module contains a runnable example application.

The [module README](https://github.com/wicketstuff/core/blob/wicket-11.x/dashboard-parent/README.md) has more details.
