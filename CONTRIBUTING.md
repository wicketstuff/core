# Contributing to Wicket Stuff

Wicket Stuff welcomes contributions: bug fixes, improvements to existing modules and new Wicket related projects. Report bugs and ideas at <https://github.com/wicketstuff/core/issues>, and send changes as pull requests.

Do not report security vulnerabilities in public issues or pull requests. Report them through [GitHub private vulnerability reporting](https://github.com/wicketstuff/core/security), and see [SECURITY.md](SECURITY.md) for the policy.
