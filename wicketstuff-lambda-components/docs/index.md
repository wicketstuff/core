Create components and behaviors from Java lambdas.

## Maven

```xml
<dependency>
    <groupId>org.wicketstuff</groupId>
    <artifactId>wicketstuff-lambda-components</artifactId>
</dependency>
```

Import `org.wicketstuff:wicketstuff-bom` in your `dependencyManagement` section to manage the version.

Source: [`wicketstuff-lambda-components`](https://github.com/wicketstuff/core/tree/wicket-11.x/wicketstuff-lambda-components)
