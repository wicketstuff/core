Searchable select boxes with tagging and Ajax-loaded options, based on Select2.

## Maven

```xml
<dependency>
    <groupId>org.wicketstuff</groupId>
    <artifactId>wicketstuff-select2</artifactId>
</dependency>
```

Import `org.wicketstuff:wicketstuff-bom` in your `dependencyManagement` section to manage the version.

The [`select2-examples`](https://github.com/wicketstuff/core/tree/master/select2-parent/select2-examples) module contains a runnable example application.

The [module README](https://github.com/wicketstuff/core/blob/master/select2-parent/README.md) has more details.

Source: [`select2-parent`](https://github.com/wicketstuff/core/tree/master/select2-parent)
