Define REST endpoints with Java lambdas.

## Maven

```xml
<dependency>
    <groupId>org.wicketstuff</groupId>
    <artifactId>wicketstuff-rest-lambda</artifactId>
</dependency>
```

Import `org.wicketstuff:wicketstuff-bom` in your `dependencyManagement` section to manage the version.

The [module README](https://github.com/wicketstuff/core/blob/wicket-11.x/wicketstuff-rest-lambda/README.md) has more details.
