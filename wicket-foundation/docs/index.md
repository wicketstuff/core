Integration of the Zurb Foundation front-end framework.

## Maven

```xml
<dependency>
    <groupId>org.wicketstuff.foundation</groupId>
    <artifactId>wicket-foundation-core</artifactId>
</dependency>
```

Import `org.wicketstuff:wicketstuff-bom` in your `dependencyManagement` section to manage the version.

The [`wicket-foundation-samples`](https://github.com/wicketstuff/core/tree/wicket-10.x/wicket-foundation/wicket-foundation-samples) module contains a runnable example application.

The [module README](https://github.com/wicketstuff/core/blob/wicket-10.x/wicket-foundation/README.md) has more details.
