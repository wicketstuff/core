Deliver Wicket events to annotated methods.

## Maven

```xml
<dependency>
    <groupId>org.wicketstuff</groupId>
    <artifactId>wicketstuff-annotationeventdispatcher</artifactId>
</dependency>
```

Import `org.wicketstuff:wicketstuff-bom` in your `dependencyManagement` section to manage the version.

The [module README](https://github.com/wicketstuff/core/blob/wicket-11.x/annotationeventdispatcher-parent/README.md) has more details.
