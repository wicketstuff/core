Wicket Spring Boot Starter

It works!

This is the default page served by the Wicket Spring Boot Starter, running on Apache Wicket 10.x. It's shown because your application hasn't registered its own WebApplication bean yet.

Next steps

Replace this page by registering your own Wicket application as a Spring bean:

  1. Create a WebApplication subclass annotated with @Component.
  2. Point its getHomePage() to your own WebPage.
  3. Optionally inject Spring beans into your pages with @SpringBean.

See the starter's README for the full Quickstart, or the Apache Wicket documentation to learn more about building pages and components.
