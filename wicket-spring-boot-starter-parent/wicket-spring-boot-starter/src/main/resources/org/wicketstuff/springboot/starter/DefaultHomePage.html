How to customize this application
  1. Create a custom Wicket WebPage:
    package com.example;

import org.apache.wicket.markup.html.WebPage;
import org.apache.wicket.markup.html.basic.Label;

public class MyNewHomePage extends WebPage {
    public MyNewHomePage() {
        add(new Label("message", "Hello, Wicket!"));
    }
}
  2. Create your custom WebApplication & register it as a Spring Bean:
    package com.example;

import org.apache.wicket.Page;
import org.apache.wicket.protocol.http.WebApplication;
import org.springframework.stereotype.Component;

@Component
public class WicketApplication extends WebApplication {
    @Override
    public Class<? extends Page> getHomePage() {
        return MyNewHomePage.class;
    }
}

Once you register your own WebApplication component, this default starter page and the auto-configured application class will automatically deactivate.
